# Python: lógica, datos e ingeniería

Este repositorio contiene ejercicios y proyectos desarrollados en Python, orientados al aprendizaje progresivo del lenguaje, la lógica de programación, el análisis de datos , su aplicación en ingeniería mecánica y mantenimiento.

## Contenido

1. Fundamentos de Python
2. Ejercicios de lógica de programación
3. Limpieza y análisis de datos con Pandas
4. Visualización con Matplotlib y Plotly
5. Aplicaciones en ingeniería mecánica y mantenimiento
6. Problemas tipo entrevista y retos de programación
7. Proyectos integradores

## Objetivo

Fortalecer habilidades prácticas en Python para resolver problemas, analizar información, crear gráficos e interpretar datos técnicos en contextos de ingeniería.

## Tecnologías usadas

- Python
- NumPy
- Pandas
- Matplotlib
- Plotly
- SciPy
